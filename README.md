# Умный кредитный кабинет предпринимателя

Прототип цифрового кредитного конвейера для малого и микробизнеса. Предприниматель подбирает кредит, подаёт заявку и проходит путь до выдачи, а кредитный аналитик рассматривает пограничные заявки. Трек «Умный кредитный кабинет предпринимателя», Альфа-Будущее Хакатон 2026.

> **Все данные синтетические.** Компании, люди и ИНН вымышлены (код региона в ИНН — несуществующий `00`). Внешние системы — бюро кредитных историй, ЕГРЮЛ/ЕГРИП, ФНС, электронная подпись, АБС — заменены моками в контейнере `mocks`.

## Быстрый старт

Нужно: Docker Desktop или Docker Engine с Compose v2, 8 ГБ ОЗУ, свободные порты 8080 и 8001. GPU и `.env` не нужны.

```bash
git clone <ссылка на репозиторий>
cd <каталог репозитория>
docker compose up --build
```

Первый запуск собирает образы и занимает несколько минут. Когда все сервисы перейдут в состояние `healthy` (`docker compose ps`), откройте:

| Что | Адрес |
| --- | --- |
| Приложение | http://localhost:8080 |
| Swagger UI | http://localhost:8080/api/docs |
| Моки внешних систем | http://localhost:8001 |

При первом старте `app` применяет миграции и загружает демо-данные, если база пустая.

Если порт 8080 или 8001 занят, задайте другой через переменную окружения:

```bash
NGINX_PORT=8088 MOCKS_PORT=8002 docker compose up --build     # bash
$env:NGINX_PORT=8088; docker compose up --build              # PowerShell
```

## Демо-учётки

Вход без паролей: на стартовой странице выбирается демо-профиль.

| Профиль | Роль | Сценарий |
| --- | --- | --- |
| `demo-approve` | предприниматель | одобрение |
| `demo-counter` | предприниматель | контрпредложение: сумма больше лимита |
| `demo-info` | предприниматель | дозапрос: не хватает данных о залоге |
| `demo-manual` | предприниматель | ручное рассмотрение аналитиком |
| `demo-reject` | предприниматель | отказ: просрочка 90+ дней |
| `analyst` | кредитный аналитик | очередь заявок и решения |

## Команды

| make | Без make | Что делает |
| --- | --- | --- |
| `make up` | `docker compose up --build -d` | собрать и запустить стек |
| `make down` | `docker compose down -v` | остановить и удалить данные |
| `make logs` | `docker compose logs -f` | логи всех сервисов |
| `make test` | `docker compose run --rm --build app pytest` | автотесты против тестовой БД |
| `make seed` | `docker compose run --rm app flask seed --reset` | пересоздать демо-данные |
| `make lock` | см. `Makefile` | пересобрать `requirements*.txt` с хешами |

## Сервисы

| Сервис | Назначение |
| --- | --- |
| `db` | PostgreSQL 16: данные и очередь конвейера |
| `app` | Flask API под Gunicorn, миграции и сид при старте |
| `worker` | воркер конвейера заявок (`flask pipeline-worker`) |
| `mocks` | моки БКИ, ЕГРЮЛ/ЕГРИП, ФНС, ЭП и АБС |
| `nginx` | отдаёт SPA и проксирует `/api` в `app` |

Документ дополняется по мере разработки: архитектура, переменные окружения и пошаговый сценарий проверки появятся здесь и в `docs/`.
